# (`cargo xtask open-posix --data`), and why: name, outcome, reason. The outcome is the suite's own
# (FAIL, UNRESOLVED, UNSUPPORTED) or ANY for the first run to tell: anything but PASS. A test of this
# list that passes is reported and does not fail the run. The list is documentation of the
