# Пути ядра без вытеснения

Внутри ядра прерывания замаскированы (спецификация 8.1), поэтому каждый путь
ниже целиком входит во время блокировки любого потока, даже самого
приоритетного. Таблица собирает такие пути с оценкой работы для анализа
времени отклика (спецификация 15.3). Путь, работа которого растёт с размером
объекта, разбивается на порции с точкой продолжения в объекте и опросом
ожидающих прерываний между порциями (`arch::irq_pending`, спецификация 7.7).
Порции и очередь очистки появятся на этапе 1.3; до него такие пути идут
одним вызовом.

| Путь | Что делает | Оценка |
|---|---|---|
| `AddressSpace::destroy` | уводит `TTBR0` с таблиц, `tlbi aside1is`, обходит дерево (512 слов на каждую таблицу уровней 0, 1 и 2) и возвращает каждую таблицу распределителю | число таблиц × 512 чтений |
| `HandleTable::release` | удаляет каждую запись и возвращает каждый кусок | число кусков × 64, не больше 16 384 записей |
| смена поколения ASID (`tlb::switch_to`) | обнуляет карту номеров (8 КБ), ищет свободный номер (до 1024 слов), `tlbi vmalle1` | постоянная: до 1024 слов карты |
