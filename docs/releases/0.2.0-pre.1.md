The first pre-release of stafeto: a POSIX system on its own capability microkernel, written in Rust for AArch64. It boots in QEMU (`virt`) on any host, with HVF acceleration on a Mac with Apple silicon, on 1 to 4 CPUs.

## Try it

Download `stafeto-0.2.0-pre.1-aarch64-virt.tar.xz`, unpack it and run `./run.sh` (`--cpus 4` for four CPUs, `--hvf` on a Mac with Apple silicon). You get a BusyBox `ash` shell; `bash`, `nano`, `htop`, `top` and `ncdu` are in the image. `exit` or Ctrl-A X ends QEMU; `run.sh` tells how to install `qemu-system-aarch64` if it is missing.

## Highlights

- **Kernel.** A small capability microkernel: synchronous IPC with priority inheritance, memory objects and mappings, interrupts as notifications, partitioned fixed-priority scheduling with a bounded non-preemptible path (at most 15,492 instructions, limit 18,000).
- **SMP.** Up to 4 CPUs with per-CPU data, one short object lock, commands between CPUs and QSBR; scheduling stays partitioned, so a real-time CPU keeps its bounds (`docs/smp.md`).
- **POSIX.** 1,035 of 1,035 required interfaces present; os-test basic 1,183 of 1,187 and Open POSIX 1,985 of 2,036 tests pass. Files, pipes, local sockets, signals, timers, threads, `mmap`, `/proc`.
- **Userland.** Services run in user space (RAM file system, pipes, terminal, processes, clock). BusyBox 1.37 gives 94 of 112 POSIX utilities; GNU bash 5.3, ncurses, GNU nano, htop and ncdu run on relibc.
- **Real-time and WCET tools.** Measured bounds checked in CI and `cargo xtask wcet` for block coverage, kernel stack depth and a static bound per call (`docs/wcet.md`).
- **Release files.** The kernel with symbols, the sources of every GPL package with our build scripts and patches, an SPDX SBOM and `SHA256SUMS`.

## Limits

- QEMU `virt` only; the PinePhone and other boards come later.
- The file system lives in RAM: changes are gone after a restart.
- No network, graphics or sound yet.
- A pre-release for trying out and testing; interfaces may still change.
