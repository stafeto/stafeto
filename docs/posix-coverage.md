# POSIX interface inventory

`cargo xtask coverage` compares exported names in relibc's `libc.a` and stafeto's `libposix_crt.a` with [POSIX.1-2024 System Interfaces](https://pubs.opengroup.org/onlinepubs/9799919799/functions/contents.html). It also preprocesses available headers for macro names. The command writes `target/measure/posix-coverage.tsv` and builds both archives when run without arguments. For an existing build, use `cargo xtask coverage --libc path/to/libc.a --crt path/to/libposix_crt.a`.

The checked-in [XSH inventory](../tests/posix/2024-xsh.tsv) records names, reference pages, headers, and option codes. Regenerate it with `python3 tools/posix-xsh-inventory.py --cache /tmp/posix-xsh-2024 --output tests/posix/2024-xsh.tsv`. The extractor reads the official pages and keeps downloaded HTML in the requested cache directory. Its current extraction covers 699 reference pages, 1,228 names, and 1,023 names outside optional regions. The cached pages are omitted from the repository.

An `exported-symbol` row has a linker-visible entry point. A `header-macro` row names a macro seen when compiling the listed header for AArch64. An `unresolved` row needs review for missing headers, preprocessing failures, inline functions, or implementation work. The command prints the header scan counts. Guest tests establish behavior, error handling, and service availability. The complete 5ж conformance gate will combine this inventory with os-test and Open POSIX results.
